# 公开分发版验证记录

日期：2026-11-02。版本：0.1.6。目标：Windows，DSH 0.2.1-rc.3 / 0.2.1-rc.5。

## 已完成

- 11 项公开 Node 测试通过，覆盖六模型点数、缓存互斥、推理用量、人民币换算、未知费用、时段、日期、路由、分叉、并发去重、旧账快照和图表分母。
- host/client JavaScript 语法检查和无依赖前端构建通过。
- Windows PowerShell 5.1 实际运行安装和卸载脚本；PowerShell 7 生成发布包。
- 安装预检自动发现桌面 DSH CLI，验证 SHA-256 和宿主版本，`-WhatIf` 不创建备份或安装缓存。
- 在含空格的隔离 `DSH_HOME` 安装现成发布包，不依赖外部 Node.js/npm；安装包持久保存到该用户目录。
- 当前 DSH 0.2.1-rc.5 上实际加载插件，读取三条虚构账目；接口 HTTP 200、无诊断；超六个月拒绝、未认证请求拒绝。
- 浏览器确认“记账”入口、30/7 天筛选、模型累计以及纵向两张饼图。演示截图仅来自虚构数据。
- 启动前后账本哈希一致；卸载后账本哈希、无关字段和原有组合包保持不变。
- 安装包内容检查与公开源文件检查，排除私人账单、会话、凭据、原始截图、本机日志和配置备份。

## 验证边界

原功能曾在 DSH 0.2.1-rc.3 的桌面界面验证；0.1.5 在 rc.5 实机确认回复尾部费用恢复。0.1.6 保留其前端和计算规则，另对便携安装、`DSH_HOME` 与公开分发进行 rc.5 隔离实测；本次没有重装旧版宿主或重复发起付费模型调用。

首版安装器仅支持 Windows。其它 DSH 版本、其它系统、未配置模型、私有折扣和未返回的缓存用量不在已验证范围内。提供方扣费仍以其账单为准。
